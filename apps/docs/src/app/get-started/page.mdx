# Choose your starting point

Choose the path that matches what you already have.

## I want to run Inframeld

[Install the development environment](/get-started/install-inframeld), then make a [health request](/clients/http). This is the supported source-based preview path. The [self-hosting guide](/self-hosting) explains the boundary between development setup and a production deployment.

## My team already has an installation

Ask your operator for its backend URL, account-site URL and supported access procedure. [Sign in to the account site](/get-started/connect), then use the interfaces your operator has enabled.

## I want to build an application

Choose [cURL](/clients/http), [Python](/clients/python), [TypeScript](/clients/typescript) or [Rust](/clients/rust). Start with an unauthenticated health request, then follow [authentication](/api-reference#authentication) for protected operations.

## I want to use the terminal

[Install the CLI](/get-started/install-cli). You can inspect its version, register credential-free targets and preview preference changes. See the [command reference](/clients/cli/commands) for the delivered commands.

The [first-answer quickstart](/get-started/first-answer) describes the complete product journey and its current availability.
