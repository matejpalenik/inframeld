# Quickstart: get an answer from your documents

The complete quickstart will take a small handbook from upload to a grounded answer in your private Project.

<Note>
  Document upload, processing and query operations are not exposed by this
  preview's public API or CLI. This page describes the intended journey and
  directs you to the working interfaces available today.
</Note>

## The first-answer journey

1. Sign in and use your ordinary private Project and its granted resources.
2. Configure the model connections needed for processing and generation.
3. Add the handbook to a collection and let its processing complete.
4. Configure a Pipeline and obtain an answer with its source evidence.
5. Follow the separate build and publication workflow when you want a Deployment to serve an approved version.

[How Inframeld works](/product/how-it-works) explains these concepts. Evaluation and release control provide further tools after a useful answer is working.

## Try the delivered interfaces

You can [install the development backend](/get-started/install-inframeld), make a [health request](/clients/http), [configure a local target](/guides/register-a-target), and work with [existing Project metadata](/guides/name-and-rename-project) when your installation supplies the necessary human authority.

The [API reference](/api-reference) is the inventory of delivered public operations. This quickstart will gain executable document and query steps as those interfaces are delivered.
