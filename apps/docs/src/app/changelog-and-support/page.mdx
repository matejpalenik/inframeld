# Changelog and support

Use the repository's [releases](https://github.com/matejpalenik/inframeld/releases) and [merged changes](https://github.com/matejpalenik/inframeld/pulls?q=is%3Apr+is%3Amerged) to identify the artifacts and source revision you are using.

## Developer preview

The current preview includes CLI version inspection, credential-free target registration/selection, existing-account browser login/logout, checked consent navigation, Project metadata operations, the supported use-only grant and retained-operation readers. Python, TypeScript and Rust SDKs consume the public HTTP contract from source packages.

The complete document-to-answer journey, broader account flows, packaged production deployment and full saved CLI credential lifecycle remain separate deliveries. [Get started](/get-started) routes to working preview examples.

## Report a problem

[Open an issue](https://github.com/matejpalenik/inframeld/issues) with:

- The task you were trying to complete.
- Application/CLI revision, artifact origin and platform.
- Minimal steps and the exact expected versus observed result.
- Safe error codes and relevant request or operation identifiers.

Remove credentials, cookies, flow URLs, private content and protected captures before sharing. For an uncertain write, retain the original context and follow [recovery](/guides/automation-and-recovery) rather than issuing another action solely for a bug report.
