# Inframeld documentation

Build grounded answers from your documents, test their quality and control which version serves your application.

<Note>
  This developer preview delivers local CLI tools, existing-account sign-in and
  the public Access and operation-inspection APIs. The complete
  document-to-answer workflow is still being delivered. Installation and client
  pages explain the supported starting paths.
</Note>

## Start here

- **Run your own environment:** [install Inframeld from source](/get-started/install-inframeld).
- **Use your team's installation:** [connect and sign in](/get-started/connect).
- **Build an integration:** make a first request with [HTTP](/clients/http), [Python](/clients/python), [TypeScript](/clients/typescript) or [Rust](/clients/rust).
- **Use the terminal:** [install the CLI](/get-started/install-cli) and [register a target](/guides/register-a-target).
