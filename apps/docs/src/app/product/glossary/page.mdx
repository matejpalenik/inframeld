# Glossary

| Term             | Meaning                                                                                           |
| ---------------- | ------------------------------------------------------------------------------------------------- |
| Admission        | The point where the server accepts an authorized action for processing.                           |
| Collection       | An exact selection of document versions.                                                          |
| Deployment       | A serving target that selects an eligible prepared version.                                       |
| Display name     | A presentation label for people.                                                                  |
| Document version | An immutable source-content revision.                                                             |
| Evaluation       | Offline evidence about answers against reviewed cases.                                            |
| ID               | A resource's permanent identity.                                                                  |
| Name             | An exact command/configuration selector.                                                          |
| Operation        | An accepted action with original meaning and a retained identity where the contract provides it.  |
| Pipeline         | Working retrieval-and-generation configuration and its prepared versions.                         |
| Project          | A scope for resources, membership and action permissions.                                         |
| RAG              | Retrieval-augmented generation: finding relevant passages and giving them to a model as evidence. |
| Readiness        | Verified preparation for a particular use.                                                        |
| Target           | A CLI registration for an installation's connection settings.                                     |

[How Inframeld works](/product/how-it-works) follows these terms through one ordinary journey.
