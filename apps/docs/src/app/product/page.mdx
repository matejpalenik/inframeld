# What is Inframeld?

Inframeld is an open-source platform for configuring models, organizing knowledge and building grounded question-answering workflows. It uses retrieval-augmented generation, or RAG: finding relevant passages and giving them to a model as evidence for an answer.

For example, your support team can use a handbook as the source for an assistant, compare answers against reviewed questions, and choose which prepared version serves customers.

## The product model

Documents and collections hold your knowledge. Processing prepares searchable passages. Pipelines combine retrieval and generation. Evaluations help you compare results. Deployments determine which prepared version receives traffic. Projects and current permissions govern access throughout.

An answer's sources help you inspect its grounding. Retrieved evidence alone does not prove that an answer is correct.
