# Check your CLI version

Find the version of the executable your shell runs before updating it or reporting a problem.

<a id="before-you-begin" />

If `inframeld` is unavailable, [install the CLI](/get-started/install-cli) first. Run these commands in your terminal from any directory.

## Print the version

<CodeGroup>

```shell
inframeld --version
```

</CodeGroup>

The command prints the executable's version. Keep it with your support report.

<a id="read-the-build-information" />

## Read build details

<CodeGroup>

```shell
inframeld version
```

</CodeGroup>

This adds build information, including the recorded revision when available and the executable's target platform. Development builds report compatibility as unverified. Use [upgrades and compatibility](/self-hosting/upgrades) when choosing artifacts to run together.
