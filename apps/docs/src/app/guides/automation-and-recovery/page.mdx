## Keep recovery tied to the original action

Retain the original installation, scope, method, canonical route and request key before a write. Reuse the documented original-operation path after an uncertain result. Generating another key can create a different operation.

An `unresolved` lookup result supplies no proof that the original action failed. Current permission and the endpoint's disclosure policy still apply. [Operations, results and errors](/api-reference/operations) defines these observation boundaries.
