# Request and response models

These views read the committed native schemas directly. Required presence, nullable values, constants, bounds and union alternatives retain their wire meaning.

## AcceptedOperationLookupResponse

Confirms original asynchronous admission with a known or explicitly unknown job reference. A known ID identifies the original work, while dispatch and current job state remain unestablished by this response. Later job inspection still requires its own interface and current authority.
