# Recover an original admission

Alice loses a grant acknowledgment. Lookup asks what the backend retained about that original request, without repeating the grant. The [owning contract](../../../.agents/skills/inframeld-application-contracts/references/operation-recovery-contracts.md#original-request-lookup) defines current authority, expected original guards and honest unknown outcomes.

The expected guard is captured before dispatch. It cannot grant permission or change the original operation. Grant lookup requires current can-use-and-grant `create-access-groups` on the original Project. A Project action-use guard cannot downgrade it.

The approved lookup contract is not yet runtime qualification. The HTTP recipe and implemented-source links are added with the endpoint. No executable CLI lookup command is delivered here. A successful lookup with Unresolved data does not establish that nothing happened. A timeout is a failed observation. Neither authorizes resubmission.
